# Fixtures

Small Next.js 16 App Router apps used as scanner inputs (snapshot tests) and for end-to-end capture tests (`e2e/`). Each app has the capture hooks `flow-checker init` writes, importing the workspace build of `@integr8-media/flow-checker` (run `pnpm build` first). Each covers one group of patterns from docs/PLAN.md section 6.

## Running a fixture

```bash
node fixtures/mock-api/server.js           # terminal 1: backend on :4010
pnpm --filter @fixtures/next-intl dev      # terminal 2: app on :3000
```

To run one with capture on: `node packages/flow-checker/dist/cli.js dev --root fixtures/next-intl` (with the mock API running).

Login for `next-intl`: any mock user email (e.g. `ada@example.com`), password `password`, OTP `123456`.
