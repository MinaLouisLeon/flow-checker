# Navigation

## AddTodoForm  src/components/AddTodoForm.tsx
push /todos/:id -> /todos/[id]  event onSubmit  success

## TodoList  src/components/TodoList.tsx
link /todos/:id -> /todos/[id]  event onClick

# Flows

## AddTodoForm submit  (/ -> /todos/[id])
1. AddTodoForm onSubmit on /
2. POST /api/trpc/todo.add
3. invalidateQueries tRPC todo.list -> GET /api/trpc/todo.list
4. push -> /todos/[id]
5. load GET /api/trpc/todo.byId
6. load GET /api/trpc/user.byId

## TodoDetail click  (/todos/[id])
1. TodoDetail onClick on /todos/[id]
2. POST /api/trpc/todo.toggle
3. invalidateQueries tRPC todo.byId -> GET /api/trpc/todo.byId
